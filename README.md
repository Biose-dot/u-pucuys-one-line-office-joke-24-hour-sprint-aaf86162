[One-Line Office Joke: 24-Hour Sprint](https://make.fun/c/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162).

A sprint that ships nothing but a retrospective about the retrospective — the meeting invite is the only deliverable, punch at the end.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> We ran a 24-hour sprint, shipped nothing, and held a retrospective about why the sprint needed a retrospective. The meeting invite was our only deliverable.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
